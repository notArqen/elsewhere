# Elsewhere

*Your sound. Somewhere else.*

Elsewhere is a single-file web app: drop in any audio and place it in 87 spaces (tunnels, stadiums, cars, boats, underwater, behind a wall, far away) with a 3-band EQ, filters, reverb, echo, drive, wobble, pitch and ambience, then export the result as WAV. Everything runs in your browser; nothing is uploaded.

**Keys:** `Space` play · `B` before/after · `↑` `↓` presets · `←` `→` seek
