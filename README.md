# Elsewhere

*Your sound. Somewhere else.*

Elsewhere is a single-file web app: drop in any audio and place it in 111 presets (tunnels, stadiums, cars, boats, underwater, behind a wall, far away) with a 3-band EQ, a sub-bass and driver-size model (tuning, boom, stickiness), filters, reverb, echo, drive, wobble, pitch and ambience, then export the result as WAV. Everything runs in your browser; nothing is uploaded.

**Keys:** `Space` play · `B` before/after · `↑` `↓` presets · `←` `→` seek
